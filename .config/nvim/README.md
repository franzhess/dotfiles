# Neovim / LazyVim

My configuration based on the [LazyVim starter](https://github.com/LazyVim/LazyVim).

- `lua/config/` contains startup, options, keymaps, and autocommands.
- `lua/plugins/` contains plugin additions and overrides.
- `lazyvim.json` records enabled extras; `lazy-lock.json` records plugin revisions.

Launch Neovim to install plugins, and use `:LazyHealth` to check dependencies.
See the [root README](../../README.md) for workstation setup and the
[LazyVim documentation](https://www.lazyvim.org/) for editor usage.
The starter's license is retained in `LICENSE`.
